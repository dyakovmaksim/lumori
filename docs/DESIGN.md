# Дизайн Lumori

Главная идея — личное рабочее пространство, в котором легко начать мысль и удобно читать длинный ответ. Интерфейс использует знакомую ясность системных приложений Apple, не копируя бренд или пиктограммы.

## Визуальный язык

Тёплый молочный фон, графитовый текст, полупрозрачные белые панели. В тёмной теме — глубокие зелёно-серые оттенки вместо чистого чёрного. Шалфейный акцент выделяет действия, пастельные карточки предлагают три способа начать работу. Центральный знак сделан в SVG, не требует тяжёлого видео или WebGL.

Шрифт — системный стек: на устройствах Apple используется системная гарнитура. Нет внешних загрузок шрифтов и трекеров. Пространство вокруг элементов и ясная иерархия важнее декоративной плотности.

## Поведение

- История слева; на телефоне превращается в выдвижную панель.
- Поле ввода закреплено внизу, сообщение растёт вверх до ограниченной высоты. На телефоне Enter вставляет перенос, отправка выполняется кнопкой.
- Модель меняется рядом с редактором, чтобы выбор относился к следующему ответу.
- Голос — способ ввода, а не отдельная обязательная беседа. Пользователь проверяет текст до отправки.
- Ответ сочетает текст, код и таблицы. Код не исполняется в браузере, внешние картинки из Markdown не загружаются автоматически.
- При чтении старых сообщений автопрокрутка прекращается; есть кнопка возврата к последнему ответу.
- Анимации ограничены opacity/transform. Учтён prefers-reduced-motion, у управляющих элементов есть подписи, модальные окна используют нативный dialog с управлением фокусом.

## Границы первой версии

Одно личное пространство, один пароль. Серверная история общая между вашими устройствами. Нет приглашений и совместного редактирования. Сайт подключён к установленному Codex App Server через ChatGPT-авторизацию. В сообщениях видны действия агента, созданные файлы доступны для скачивания. Работа ограничена папкой диалога и отдельным системным пользователем.
