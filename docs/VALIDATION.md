## Обновление: независимый акцент

Розовый больше не является отдельной светлой темой. Базовое оформление (светлое, тёмное, системное) и акцент (шалфей, розовый, голубой, лаванда) имеют отдельные настройки и ключи хранения для каждого аккаунта. Прежнее значение `pink` переносится в розовый акцент с системным оформлением. Сборка и TypeScript проходят. Изменение затрагивает только интерфейс; службы Codex и история не изменяются.

Проверено в Chromium на опубликованном сайте: все 8 сочетаний двух тем и четырёх акцентов; тёмная тема с розовым акцентом сохраняется после перезагрузки. Проверен перенос старой настройки `pink`. Снимки тёмного интерфейса с розовым акцентом сохранены для компьютера и телефона.
